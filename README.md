# Sales Data Analysis using Python and Pandas

## Objective

The objective of this project is to analyze sales data using Python and Pandas.

## Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset

The dataset contains 100 sales records with the following columns:

- Date
- Product
- Category
- Sales
- Quantity
- Region

## Analysis Performed

- Loaded the CSV file using Pandas
- Inspected the dataset using `head()`, `shape`, and `info()`
- Checked and handled missing values
- Filtered sales data using conditions
- Demonstrated the difference between `loc[]` and `iloc[]`
- Grouped sales by Category, Region, and Product
- Calculated total sales using `groupby()` and `sum()`
- Created a bar chart for sales by category
- Created a line chart showing sales trends over time

## Key Results

- Highest-selling Category: Electronics
- Highest-selling Region: North
- Highest-selling Product: Laptop
- Total Sales: 10,155
